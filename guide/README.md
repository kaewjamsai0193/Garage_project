## โครง backend: หนึ่งโดเมนหนึ่งโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `<โดเมน>/router.py` | URL + ตรวจสิทธิ์ → เรียก service → คืน schema · อ่านข้อมูลธรรมดาได้ **แต่ไม่เขียน** |
| `<โดเมน>/service.py` | กฎธุรกิจ · ล็อก · **การเขียนข้อมูลทุกอย่าง** |
| `<โดเมน>/schemas.py` | รูปแบบข้อมูลเข้า-ออก · ต้นทุนแยก schema (`XxxAdminOut`) |

ของกลาง: `main.py` `db.py` `auth.py` `models.py` `money.py` `schemas.py` · โดเมนเรียกกันด้วย import ตรง ๆ

## กติกาเขียนโค้ด

- ชื่อฟังก์ชันขึ้นต้นด้วยกริยา ไม่ย่อจนต้องเดา (`list_products` `round_money` `formatMoney`)
- comment / docstring บรรทัดเดียวทุกฟังก์ชัน: ทำอะไร รับจากไหน ส่งไปไหน
- เงื่อนไขยาว ตั้งชื่อก่อนใช้ (`unit_changed = ...` แล้วค่อย `if unit_changed`)
- หน้าจอ: `<ข้อมูล>ListPage` / `DetailPage` / `FormPage` · ของที่หลายหน้าใช้อยู่ `components/` · หน้าไม่ import จากหน้าอื่น
- เขียนเฉพาะที่เฟสนั้นใช้ ไม่เผื่อเฟสหลัง
- ก่อน commit: `ruff check` + `ruff format` + `npm run format` + `npm run build` + pytest เขียว

## ทำหนึ่งเฟส

```
models.py → alembic revision --autogenerate (เปิดอ่านไฟล์ที่ได้ทุกครั้ง) → upgrade
→ เทสต์ (แดง) → service/router (เขียว) → หน้าจอ → กดจริงทั้งจอคอมและมือถือ → format → commit
```
